Tasks format 1.0: document schema with lists, built-in and custom fields, recurrence rules, `parse`/`stringify`/`validate` for JSON, YAML and TOML, Markdown task files (`parseMarkdown`/`stringifyMarkdown`/`isTaskFile`), `merge()` for sync with conflict repair, `occurrences()` for expanding recurrence across time zones, `completeTask()` for completing one-off and recurring tasks, query helpers (`statusOf`, `priorityOf`, `isComplete`, `isOpen`, `isOverdue`, `blockers`), and `toICS`/`fromICS` for iCalendar.
